ABOUT THE PROJECT

AI for Tropical Cyclone Intelligence

This project explores the use of artificial intelligence and multi-source satellite data to support tropical cyclone identification, classification and prediction.

The final system will combine a web interface, data processing pipeline and machine learning model into a single platform.
